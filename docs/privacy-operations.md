## amenowa側の掲載方針

同日、ユーザーが「利用する予定です」等を「利用しています」等の公開用表現に変更することを承認したため、掲載案の注記を取り除き、利用・保管・管理の文言を更新した。デモでは送信・保存しない旨のみを表示し、liveビルドではこのデモ注記を表示しない。以下は掲載文の方針であり、現行の社内体制やメール設定を実査した結果ではない。

| 項目 | 掲載した方針 |
| --- | --- |
| 管理責任者 | 株式会社amenowaの代表取締役。個人名や新たな担当者の任命はしていない |
| 取り扱う人 | 問い合わせ対応に必要な担当者のみ |
| 当社側の保存先 | 業務用メールと業務に必要な保存先。私的なメール・保存先へ転送しない |
| 通常の問い合わせの保存期間 | 対応完了後、原則1年間。一般の問い合わせに法律で一律1年の保存を求めている、という意味ではない |
| 例外 | 継続取引・紛争対応・法令上の保存義務がある情報は必要な範囲と期間で別途管理 |
| 見直し | 毎月、対応完了日・保存期限・継続保管の理由を確認 |
| 削除・廃棄 | 受信・送信メール、添付、端末の複製、ごみ箱を対象に削除。紙は裁断等で廃棄 |
| バックアップ | メール等の提供元の保持・削除条件を確認。復元時も過去の削除を反映 |
| 相談窓口 | 問い合わせフォーム経由で受け付け、必要に応じ本人確認後に法令に基づき対応 |

この変更は文章とデモの導線の変更のみ。メールの保持期間、自動削除、アクセス権限、バックアップ、実際の担当者の設定を変更するものではない。

## FormSubmitで確認できた事実

- [公式ドキュメント](https://formsubmit.co/documentation)の「Access to submissions archive」に、送信内容を30日間保存する旨の記載がある。[FAQ](https://formsubmit.co/help)にも30日間の記載がある。
- この30日はFormSubmit側の送信内容アーカイブの説明であり、amenowaが受信したメールの保存期限ではない。また、すべてのログ・バックアップまで30日後に完全削除されるという保証には拡張しない。
- [プライバシーポリシー](https://formsubmit.co/privacy.pdf)では、フォームで取得する情報の管理責任はサイト側にあり、FormSubmitはサービス提供等のために処理すると説明している。
- 確認した公式ドキュメント・FAQ・プライバシーポリシー・運営元の会社紹介から、サーバーの所在国・地域は確認できなかった。運営元の所在地やIPアドレスからデータの保管国を推定していない。

## 本番前に残る実務

1. 代表取締役による管理と必要な担当者のアクセス範囲を実運用で確定する。
2. info@amenowa.co.jpで使うメールサービスと端末の保存先、保管国・地域、バックアップ保持・削除条件を確認する。
3. FormSubmitの保管・処理を行う国・地域、再委託先、アーカイブ以外の保持・削除条件を確認する。提供元への照会が必要な場合は、ユーザーの依頼のもとで行う。今回、外部へ照会メールは送信していない。
4. 国外取扱いがある場合の必要な対応を整理する。参考：[個人情報保護委員会「外国にある第三者への提供編」](https://www.ppc.go.jp/personalinfo/legal/guidelines_offshore/)。単に「国外で処理される可能性」と書くだけで必要な手続が完了したと扱わない。
5. 掲載した1年間の保管と月次見直しに沿って、実際の保管・削除手順を用意する。自動削除が設定済みとは扱わない。
6. 掲載文と実運用の一致を確認した後、既存のFormSubmit有効化・受信テストを行う。デモ注記はliveビルドでは表示しない。

デモは従来どおり実送信・保存なし。GA4の非本番除外、noindex、現在のWordPress本番は変更していない。
